# Discovery Web Piscine - Project Documentation

## Project Overview
This repository contains the foundational web development and Git version control exercises for the Discovery Web Piscine.

## Why Git Makes Development Easier

Git streamlines and secures software development through three core capabilities:

1. **Safeguarding Code:**
   Git creates immutable snapshots of the project at every commit. If a mistake or bug is introduced, developers can safely revert to a previously working state without losing history or progress.

2. **Tracking History:**
   Every change is cataloged with precise metadata, including the author, timestamp, and a clear description of the modifications made. This provides full auditability and context for the codebase's evolution.

3. **Enabling Team Collaboration:**
   Through branching and remote synchronization, multiple developers can work simultaneously on different features without interfering with each other's work. Git automatically manages code merging and conflict resolution.
